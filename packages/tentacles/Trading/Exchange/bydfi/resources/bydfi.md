# BYDFi account setup

## Create an account

- Fill <a href="https://www.bydfi.com/en/register" rel="nofollow">this BYDFi</a> registration form
- Create an API key with trading permissions (no withdrawal)
- Add the key and secret to your OctoBot exchange configuration
